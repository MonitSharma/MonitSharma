- [Quantum-Codebooks](https://github.com/MonitSharma/Quantum-Codebooks): worked solutions for Qiskit, PennyLane, Q# and more
- [Quantum-Papers-Explained-with-Code](https://github.com/MonitSharma/Quantum-Papers-Explained-with-Code): papers implemented and explained
- [Qiskit-Summer-School-and-Quantum-Challenges](https://github.com/MonitSharma/Qiskit-Summer-School-and-Quantum-Challenges): IBM summer school and challenge solutions since 2020
